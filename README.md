# Chozhan Foundation website

Static multi-page site, ready for Cloudflare Pages or GitHub Pages.

## Deploy
Upload all files in this folder to Cloudflare Pages (direct upload), or commit them to a GitHub repository connected to Cloudflare Pages. Build command: none. Output directory: root.

## Before launch
- Confirm all program descriptions and official organization information.
- Configure a real form endpoint or email provider for volunteer/contact submissions.
- Integrate a verified payment provider before accepting donations.
- Replace any placeholder content and check accessibility, privacy and donation compliance.
- An admin dashboard requires authentication and a backend (not included in this static prototype).
